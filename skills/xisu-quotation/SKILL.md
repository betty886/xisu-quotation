# 吸塑报价核算

按使用者提供的订单和工厂配置执行可复核的报价。保留原始输入、参数来源、计算过程及复核状态。
本 Skill 包含本机报价界面、可执行算价脚本和公开参考参数。先读取订单及参数，运行脚本取得结果；价格和设备参数均可按使用者实际情况修改。

## 打开报价界面

Windows 可运行技能目录中的 `启动报价台.cmd`；其他系统可在技能目录执行 `node scripts/web-server.cjs --open`，需要 Node.js 18 或更新版本。服务仅监听本机，关闭终端即停止。使用自有参数时，在界面命令后追加 `--config 参数文件.json`，聊天算价也使用该配置文件。界面与聊天使用同一个算价程序。

## 内置公开参考数值

固定收费与设备参数记录在 [参考配置](assets/parameters.reference.json)，以下数值与该文件一致。
使用者未提供自己的收费配置时，采用这套参考规则并写明来源，不再逐项要求使用者填写小单费和加工费。
使用者提供的有效配置优先用于设备、加工费和普通材料；植绒单价与比重按当前厚度联网核定。同一来源相互冲突时先核对。设备及收费是否适合其工厂仍须复核。
参考配置包含普通材料价格、比重、收费和含税系数1.08，可用于参考报价。植绒单价与比重联网核定。植布参考价16元/平方米。实际采购与设备条件可能变化，正式报价前由使用者核对；用户提供的有效参数优先。

## 植布入口

材料为“植布”时，必须先完整读取 [植布规则](references/cloth-rules.md)。采用参考配置的 `cloth` 字段：整张长≤110cm、宽≤70cm（含出血及边料），只算原方向，禁止旋转90°；缺模具默认阴模，明确阳模则保留。固定加工费参考3元/张，不加穴数档差。
植布材料参考价16元/平方米、含税系数1.08，均可由使用者修改。植布不要求厚度、克重或比重，不执行高度估厚。

## 1. 收集订单与参数来源

读取使用者明确提供的订单、配置或本次说明。核对同名字段的冲突；保留原值，不悄悄覆盖。
对每项采用值记录来源：本次输入、已确认配置、实测、净重反推、经验估厚或初步模具假设。
同一计算中统一币种与单位；尺寸用 cm；普通/植绒厚度用 mm、净重用 g、密度用 g/cm³、片材价用未税元/kg；植布价格用未税元/平方米。

| 信息组 | 核对内容 |
|---|---|
| 产品 | 形状、形状所需尺寸、排版外框、产品高度、材料、颜色、订单数量 |
| 厚度 | 实测原片厚度；没有实测时检查净重及其口径；再检查是否允许经验估厚 |
| 模具与设备 | 阴模或阳模、总出血位、间距、机器最大片材长宽、各方向两端边料合计 |
| 材料 | 材料与颜色精确对应的价格、价格日期、核准状态、密度 |
| 加工与小单 | 材料基础加工费、穴数档位及档差、小单张数区间及整单费用 |
| 计价 | 不良率、含税系数、额外目标毛利率、含税或未税的整单口径、最低毛利策略（若有） |
| 原额转收 | 模具、包装、其他费用及运费的整单金额或完整计算依据；明确哪些项目为零 |

材料与颜色必须精确匹配。缺少该组合的价格或普通/植绒所需密度时，列出缺项，不能借用另一材料或颜色。植布不需要密度。
采用已列明的材料与颜色的公开参考价格、密度、加工费及含税系数1.08；允许使用者覆盖，记录来源。植绒单价和比重按本单实际厚度联网核定，结果待复核。未知组合不能借用其他颜色或材料的参数。
价格日期或适用性未核准时，即使可以计算，也只能给带来源说明的初步结果。

## 2. 先校验，再处理缺失值

区分“未提供或明确标记未知/null”和“提供了无效值”。不要用真假判断或强制转数字把二者混在一起。

- 数量必须是正整数；尺寸、采用的厚度、净重、密度、材料价必须为有效正数。植布不采用厚度、净重、密度，这三项不作必填或金额校验；植布材料面积单价仍须为有效正数。
- 不良率和毛利率使用小数，取值范围见计算规则；不要把 `3` 猜成 `3%`。
- 出血、间距、边料和明确允许为零的费用可为零；正数必填项中的零不能被默认值替换。
- 负数、非数字、无穷值、布尔值、不支持的模具名称、冲突单位及无效区间应先核对。
- 验证可用幅面为正、能排下产品、普通/植绒加工费档位覆盖本单穴数、小单区间无重叠且覆盖本单。植布不匹配加工费穴数档位，另检查110×70cm整张上限和禁止旋转。
- 真实订单缺必要参数或存在无效输入时，停止输出金额，列出需要补充或更正的具体字段。

`price_confirmed: false` 表示价格尚未核准；`is_demo: true` 表示教学数据。两者都不能支持正式报价。
已确认但日期较早的价格也不能被描述为当前市场价；由使用者确认该价格是否仍适用。

## 3. 处理允许的初步假设

本节厚度处理仅适用于普通/植绒；植布直接按独立规则跳过厚度与重量路径。

额外目标毛利率未指定时，明确采用 `0` 并披露；使用者明确给出的配置值视为其已指定。
零表示不再额外按目标毛利放大，不表示加工收费没有利润，也不表示整单净利润为零。

| 情况 | 处理 |
|---|---|
| 模具确实缺失，且允许初步模具默认 | 普通/植绒暂按阳模；植布暂按阴模。记录采用值及“确认后重新核算” |
| 模具确实缺失，但未允许默认 | 列为缺项；不替使用者选择正式模具 |
| 有有效实测原片厚度 | 直接使用，不进行高度估厚或 5 丝归整 |
| 普通材料只有有效净重 | 按实际投影面积和核准密度反推等效厚度，标注估算 |
| 植绒材料只有有效净重 | 确认是植绒后成品克重或植绒前裸片克重，联网反推裸基材参考厚度；服务不可用时阻断，不以普通材料公式替代 |
| 厚度与净重都确实缺失，且已明确启用高度估厚 | 依计算规则提出参考厚度，记录原值、归整值和经验规则来源 |
| 厚度或净重已填写但无效 | 阻断；不能用高度推算掩盖错误 |

以采用配置的 `allow_preliminary_male_mold_default`、`allow_height_based_estimate` 或使用者明确说明判断是否允许。公开参考配置启用这两项；教学配置只启用缺模具默认。输出应说明启用来源，使用者可关闭。
高度估厚是可选择的经验方法，不是行业强制标准；未启用时保持缺项。上述厚度推算与零厚度阻断适用于普通/植绒的采用字段，植布分支不执行厚度推算。
缺模具默认、净重反推或高度估厚均标为初步报价，保留 `pending_review`；不能自动变成 `confirmed`。
不得承诺默认阳模一定不会亏损，或确认阴模后价格一定下降。

## 4. 材料参数

普通材料使用所选材料和颜色对应的参考单价与比重；植绒材料根据裸基材厚度联网核定本次材料单价和比重，公开文件不含核定过程。

植绒仅有克重时，需联网请求 `https://tonghoupack.com/quote/api/flock-thickness`。请求只发送材料、颜色、形状、尺寸、克重和称重阶段；不发送客户信息、订单数量或报价。联网服务使用参考工艺得到裸基材参考厚度；然后按该厚度联网核定植绒单价和比重，实际样品需要复核。网络或服务不可用时停止植绒报价并稍后重试，不得静默套其他计算方法。

植绒不论填写厚度、填写克重还是按高度估厚，都需要联网核定单价和比重；连接失败时停止报价，不使用固定值代替。本地配置中植绒单价和比重不影响联网核定结果，其他可配置参数仍生效。同步函数 quote 不支持植绒，调用异步 quoteWithFlockWeight 或使用 CLI。

聊天报价的订单 JSON 在只填植绒克重时必须同时指定 `weight_g` 和 `weight_basis`：`finished` 表示植绒后成品单件克重，`substrate` 表示植绒前裸片单件克重。称重阶段不明确时先核对。反推厚度显示为参考值，保持 `pending_review`。

## 5. 执行计算与核对

在技能目录运行 `node scripts/quote.cjs 订单.json`，默认读取 `assets/parameters.reference.json`；自有配置需以该参考配置为基础复制修改，并作为第二个参数：`node scripts/quote.cjs 订单.json 自己的参数.json`。可执行 `node scripts/quote.cjs scripts/order.sample.json` 核对默认参数，PET透明示例预期未税0.1305、含税0.1410元/件，状态为 `pending_review`。脚本按计算规则完成排版、材料费、加工费、小单费与报价。教学参数文件是独立示例格式，不能当作脚本的参考配置直接使用。
使用十进制或精确单位处理档位边界、5 丝归整和金额取整。保留中间精度，只在规定的位置取整。
记录本次实际执行的输入、关键中间值和结果，能够说明哪些数值已经运行核验。
没有执行工具时，只能说明方法、整理输入或给出待核对公式；不得编造“已验证”的单价、金额或测试结果。

核对以下关系：

- 普通/植绒计算两方向并择优；植布仅原方向，标明禁止旋转及有效上限。
- 连续计价张数、排产整张数和小单张数分别使用，未互相替代。
- 普通/植绒每张加工费为材料基础费加档差；植布为固定每张加工费，不加档差。
- 原额转收费用整单只计一次，未参与毛利放大或含税系数计算。
- 单价向上取四位，再乘数量并四舍五入到两位，整单金额与所报单价一致。
- 未提供最低毛利策略时，写明“未设置底价判断”，不声称已通过底价审核。

## 6. 按固定顺序输出

1. **用途与状态**：教学、初步或经复核的报价；`blocked`、`pending_review` 或已获确认的 `confirmed`。
2. **输入与来源**：币种、单位、材料颜色、价格日期、价格核准情况、实际值与采用的假设。
3. **面积与厚度**：投影面积、排版外框、厚度来源；估厚时列原值、归整值及“参考厚度，非实测”。植布改列整张面积平方米，厚度/净重/比重不参与。
4. **排版比较**：阴阳模占位公式，两方向横排、纵排、穴数、片材尺寸和面积，以及选择原因。植布只列原方向，并写“禁止旋转，不计算第二方向”，核对110×70cm整张上限。
5. **单张与张数**：片材重量、单张材料费、加工费档位与档差、连续计价张数、排产张数、小单张数。植布不报重量，改列面积单价与固定每张加工费。
6. **费用拆分**：材料、加工、小单费及各项原额转收费用；说明运费依据。
7. **建议价**：产品计价成本、整单未税成本、额外毛利率、含税系数、取整前后单价、相应整单金额。
8. **待核对项**：估算、缺失、无效或冲突字段、价格有效性、工艺适配和底价策略；说明哪些结果已由工具核验。

计算完整不等于获得正式确认。教学、假设或尚未核准参数的结果保持 `pending_review`；有阻断项则用 `blocked`。
补齐实际参数并完成使用者复核后，重新核算，再按其明确确认记录正式状态；保留此前版本及来源标记。
