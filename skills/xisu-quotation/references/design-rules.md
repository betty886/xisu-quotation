## 1. 适用边界与尺寸基准

本模块生成可复算的初步尺寸方案。支持规则矩形与圆形、单腔、直壁正拔模、放入式配合。几何是理想尖角包络，尚未构造圆角、支承筋、抓手、卡扣、倒扣、台阶或异形产品曲面；不会生成加工图、CAD/CAM、铝坯、水路或整套模架。

| 对象 | 定义 |
|---|---|
| 被包装产品包络 | 规定摆放方向下含突出部分的最大实体外形；不是吸塑尺寸 |
| 使用净腔底 | 完成覆层后的理想内底尺寸；存在圆角时还要检验真实可用空间 |
| 使用净口 | 完成覆层后，内侧壁与上口平面虚拟交线的尺寸 |
| 净深 | 使用内底基准到使用口沿基准的距离 |
| 裁切外形 | 净口加两侧指定平面边宽，指成品裁切轮廓 |
| 接触特征 | 塑料表面与模具接触的一侧、在最终稳定状态下的对应底/口/深目标 |
| 模具参考尺寸 | 接触目标按明确收缩定义补偿后的单穴几何参考 |

设计统一mm，报价统一cm。内部保留计算精度，不能先把cm整数化或把“丝”当作产品尺寸单位。裁切尺寸带入报价时向上保留0.01mm，避免显示归整使外形反而缩小；此精度是数值传递精度，不是加工精度保证。

## 2. 输入与缺项

运行：`node scripts/design-tray.cjs 设计输入.json`。库函数：`const {designTray}=require('./scripts/design-tray.cjs')`。成功的几何方案仍为pending_review；错误输入为blocked且CLI退出码2。未给收缩等参数只让模具部分待定，不抹去已能计算的吸塑概念方案。

`product`必填，字段如下：

| 字段 | 含义 |
|---|---|
| shape | rectangle或circle；圆形length为直径，若同时给width须与直径一致 |
| unit | mm或cm，必须明确 |
| length/width/height | 正数或严格十进制数字字符串；矩形三项必填，圆形无需width |
| dimensions_are_maximum | true表示用户声明该输入是最大包络；否则保留最大尺寸待核实 |
| source | 客户原话、测量、图纸版本等来源说明，不凭来源文字自动认定工程批准 |

`design`为可选对象：

| 字段 | 未提供时的试算起点 | 口径 |
|---|---:|---|
| clearance_per_side_mm | 1 | 单侧放入间隙，0可用但须复核；负数不作为卡紧配合 |
| draft_angle_deg | 3 | 相对脱模方向的正拔模角，单位度 |
| rim_to_trim_mm | 8 | **完成后使用净口到裁切线**的单侧平面距离，包含侧壁转折区的占位 |
| pocket_depth_mm | 产品高度 | 使用净深；小于产品高时显示露出量 |
| forming_negative_tolerance_mm | 0，仅试算 | 整个使用净腔长或宽的最大负偏差补偿，只加一次；未提供不等于工厂公差是0 |
| quote_height_mm | 净深，仅初估 | 带入原报价程序的成型外高；实际样品外高已知时用其覆盖 |

这些默认值是为了形成可讨论方案所作的软件选择，没有被本用户核准为工艺标准。脚本记录采用值、单位、来源及是否假设；显式输入也只表示用户提供，不表示已经试模通过。产品实际最大值、公差链、角部干涉、成型偏差和裁切偏差仍需复核。

`fit_mode`支持loose。要求定位夹紧、卡扣或倒扣时，先取得产品图纸、材料与工艺条件，交工程设计；不要通过填负间隙替代。

## 3. 净腔、开口和裁切外形

令P为某方向采用的产品最大尺寸，c为单侧间隙，e为整个使用净腔尺寸的负公差补偿，H为净深，a为拔模角，F为净口至裁切线的单侧距离：

```
净腔底 B = P + 2c + e
净开口 O = B + 2H × tan(a × π / 180)
裁切外形 T = O + 2F
产品露出量 = max(0, 产品高度 − H)
```

矩形对长、宽分别运算；圆形对直径运算。客户只报标称尺寸时可暂用该值预估，但必须保留“最大包络/尺寸公差未知”；不得把结果写成已验证的最小配合间隙。

这里的F不是工厂有时所说的“从裸塑料内口量起的翻边”。尤其有植绒时两个基准不同。若要采用工厂另一种基准，应先明确换算后输入，不能在同一订单混用。

e必须对应最终使用净腔。只知道阴模外侧成型公差时，尚不能忽略壁厚变化和覆层变化，直接当成使用净腔已保证公差。首版没有做全套公差叠加和外盒适配检验。

## 4. 覆层与阴阳模接触特征

`lining.type`为none、flock或cloth。none表示没有增加使用腔占位的覆层，其补偿可为0。flock/cloth必须提供以下三个有效偏置与source才能算模具接触面；未知值保持缺项：

- `bottom_offset_mm`：裸塑料内底对应特征相对使用净底的单侧有效增量。
- `opening_offset_mm`：裸塑料内口对应特征相对使用净口的单侧有效增量。
- `depth_offset_mm`：裸塑料内深减使用净深，是有符号的基准净深差；通常涉及底部与翻边覆层厚度之差。

设这三项为gB、gO、gH，则裸塑料内表面目标：

```
Bi = B + 2gB
Oi = O + 2gO
Hi = H + gH
```

普通阳模（tooling.mold_type=male）采用此内表面作为接触目标。普通阴模（female）还需tooling中的同名bottom_offset_mm、opening_offset_mm、depth_offset_mm，分别为塑料外底/外口对应特征对内表面的单侧有效增量，以及外接触深度减内深的有符号差：

```
Bc = Bi + 2bB
Oc = Oi + 2bO
Hc = Hi + bH
```

有效偏置必须来自对应特征的实测或CAD。**不是把原片厚填三遍，也不是随意在同一高度量外宽减内宽再除以二。** 有拔模时底面与翻边面的位置改变，会影响相应虚拟交线尺寸。bH通常为底部成型厚度减翻边成型厚度；需要依据实际基准计算。

保留tooling.source说明其适用材料、工艺/机台、基准与记录版本。缺source的有效数值也不会获得工程核准状态。分别复核接触面的底、口、深及`atan((Oc−Bc)/(2Hc))`；非正深度、底大于口等应阻断。不自动把用户输入改成较合理值。

原报价的厚度、净重反推厚度、高度估厚用于成本估算，与这里的成型局部偏置是不同数据。绒毛切长也不等于成型后有效占位。上下底圆角、局部减薄、堆叠和抓取需要实物/CAD另行验证。

## 5. 收缩补偿

tooling.shrinkage_fraction使用小数：0.005表示0.5%。也可分别填三方向：

```json
{"length":0.005,"width":0.004,"height":0.003}
```

约定s=(模具参考温度尺寸−最终稳定接触特征尺寸)/模具参考温度尺寸，则：

```
模具参考尺寸 M = 接触目标 D / (1 − s)
```

一个系数表示暂按三方向一致；应明确是否适合实际片材方向。圆形成品在两平面方向采用不同收缩系数时，得到的是椭圆模具包络，不得仍称等直径模具。

未提供s时模具尺寸留空。显式0可以计算，但仍待核实其实际依据。若工厂记录为“相对成品的放大补偿率a”，应先按s=a/(1+a)换算，不能把a原样当s；也不要重复叠加已包含在经验补偿中的热膨胀。

不按PET/PS/PP名称附加统一收缩常数。模温、取向、接触时间、脱模、冷却与材料牌号都可能改变实际补偿。计算完成只得到reference_only，tooling_release始终false。

## 6. 报价衔接

先展示尺寸方案，使用者明确接受后再用`quote_dimensions`填报价订单。不要把原产品尺寸直接拿去报价，也不要把模具补偿后的尺寸当成吸塑成品尺寸。

1. 复制生成的shape、length_cm、width_cm、height_cm；记录来源是产品推算的初步方案。
2. 若已有吸塑尺寸不同，列出冲突，等使用者选用哪版后再计算，不静默覆盖。
3. 补订单材料、颜色、原片厚度或吸塑制品净重、数量及原有其他参数。被包装产品的重量不能填为吸塑制品净重。
4. 若模具已经明确，带入同一mold_type；没明确则执行原报价的初步假设并披露。
5. 用既有quote.cjs核算。原费用、含税1.1及排版程序继续执行；本模块不另加材料单价、不改加工费、不制造模具费。

本次F已包含在裁切外形T内。原阴模总出血/阳模高度排版余量、机器边料和穴间距仍按原报价口径独立处理，不能再把F填到这些字段里。完整排版是成本预估，不能称为已经完成工程排穴及模架设计。

界面 `/design` 可以只输入产品尺寸做预估，不必先知道订单数量。勾选“按本方案做初步报价”后才允许带入；继续修改设计会撤销旧交接。主报价界面重新校验交接，标明待样品确认。手改尺寸/模具后旧设计关联不再有效。

## 7. 示例和现场复核

运行 `node scripts/design-tray.cjs assets/design.example.json`。示例是虚构产品100×60×20mm，1mm单侧间隙、3°、8mm边宽、无覆层、阳模，但没有收缩率。

| 输出 | 几何值 |
|---|---|
| 使用净底 | 102×62mm |
| 使用净口 | 约104.096311×64.096311mm |
| 裁切外形 | 约120.096311×80.096311mm |
| 带入报价长宽 | 12.010×8.010cm，采用120.10×80.10mm |
| 报价高度 | 2cm，仅本例采用的初估值 |
| 模具参考尺寸 | 待定，缺收缩参数 |

若为演示另给s=0.005，阳模底长参考值为102/0.995≈102.512563mm；该数字仅演示公式，绝非PET默认收缩或加工批准。

现场至少复核：产品摆放与凸出点、最大尺寸与公差、放入松紧与取出方式、圆角/筋位、露出高度、净口边宽基准、实际成型外高、阴阳模接触面、覆层工艺、实测成型偏置、材料方向与收缩定义、实物打样。按工厂确认的案例逐步建立参数档案。

## 8. 工程参考来源

以下来源支持工艺原则；本计算器的1mm/3°/8mm试算参数和理想包络公式是本功能的实现选择，**不是从这些材料指南抄得的通用生产规范**。

- [SIMONA Boltaron：Mold Designs and Factors](https://www.boltaron.com/thermoforming/mold-designs/)：模具类型对细节与厚度分布的影响；收缩随片材取向、模温、接触时间及阴阳模配置而变。
- [SEKISUI KYDEX：Determining Wall Thickness，TB 140F](https://kydex.com/technical-resources/determining-wall-thickness-for-kydex-thermoplastic-sheet-tb-140f/)：原片会因拉伸减薄，局部壁厚分布不同，面积法不能保证所有位置厚度一致。该资料的材料数值不直接套用PET/PS/PP包装。
- [Formech：Male and Female Tooling](https://www.formech.com/blog/formech-technical-newsletter-male-and-female)：应识别具体型腔与片材接触的一面；复杂组合不能只看整副模具名称。
