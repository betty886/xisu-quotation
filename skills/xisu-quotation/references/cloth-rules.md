# 植布报价规则

植布按整张片材面积计价，和普通塑料按重量计价、植绒成品片材报价分别处理。
本文件定义植布分支；[公共计算规则](calculation-rules.md)中的张数、小单费、毛利、原额转收和取整规则继续适用。

## 输入及参考配置

读取 [公开参考配置](../assets/parameters.reference.json) 的 `cloth` 字段。植布固定加工费参考值为 **3元/张**，使用者可明确提供非负金额覆盖；无论多少穴都不加普通材料穴数档差，超过100穴也保持固定加工费。
植布参考材料价 `cloth.price_per_m2` 为16元/平方米，含税系数 `tax_multiplier` 为1.1，使用者可以提供有效正数覆盖。
同时核对本单颜色、价格日期、核准状态、产品形状及外框尺寸、数量、间距、边料、小单费和原额转收费用。
固定加工费为0可以接受并记录来源；负数、布尔值、非数字或非有限数阻断。材料价显式为0必须阻断，不能套用默认价。

植布不需要厚度、净重或比重，不执行净重反推或高度估厚。已有这三个字段是其他材料遗留输入时，保留原值并说明本分支不使用，不让它们影响植布金额。
普通材料仍须遵守实测厚度优先及显式零厚度阻断；这条豁免只适用于植布。

## 模具与方向

模具缺失或为 null 时默认阴模，记录“植布模具暂按阴模，确认后重新核算”，保持 `pending_review`。
明确选择阴模或阳模时直接使用，不被默认值覆盖；无效名称先纠错。
阴模占位 `X=L+b，Y=W+b`，b为该方向总出血，参考值1cm；阴模不加高度。
阳模占位 `X=L+H，Y=W+H`，高度须为有效正数。

**只计算原方向：长沿长、宽沿宽，禁止旋转90°。** 不能在放不下时交换产品长宽、机器长宽或上限，也不能偷偷选择更高穴数的旋转方案。

## 110×70cm整张上限

有效最大片长 `ML=min(使用者或通用配置的最大片长,110)`；有效最大片宽 `MW=min(使用者或通用配置的最大片宽,70)`。
110×70cm限制的是**实际整张片材**，已包含出血、产品间距和两端边料。不能先把产品排满110×70再在外面加边料，也不能扣过一次边料后再额外扣第二次。
通用设备更小时使用更小值；更大的设备和阳模选择都不能放宽植布上限。

```text
c=floor((ML-EL+g)/(X+g))
d=floor((MW-EW+g)/(Y+g))
n=c*d
SL=c*X+(c-1)*g+EL
SW=d*Y+(d-1)*g+EW
S=SL*SW
```

EL/EW为每方向两端边料合计，g为间距。c或d不足1、SL>ML或SW>MW时阻断，不尝试旋转补救。110×70cm恰好可排时允许。
使用者提供实际模穴和片材尺寸时，同样检查上限和固定方向，不能借实际模具覆盖绕过约束。

## 材料、加工与整单

```text
每张材料费 = S/10000 * 植布未税元/平方米
每张加工费 = 本单固定加工费（参考3元/张）
连续计价张数 Nc = Q/n/(1-r)
备料整张数 Np = ceil(Nc)
小单判断张数 Ns = Q/n
Cmat = 每张材料费 * Nc
Cproc = 固定每张加工费 * Nc
C = Cmat + Cproc + Csmall
F = 模具费 + 包装费 + 其他费用 + 运费
未税原始单价 = [C/(1-m)+F]/Q
含税原始单价 = [C*tax_multiplier/(1-m)+F]/Q
```

小单费采用同一公开参考规则：Ns<500收500元，500≤Ns<1000收300元，Ns≥1000收0元；使用者可提供自己的完整小单规则。Ns不加不良率、不取整，小单费整单只收一次。
材料和加工用连续Nc计价，不使用备料Np代替。F整单一次，不参加毛利放大或含税系数计算。
毛利率m使用小数，未指定额外目标毛利时采用0并披露。先将原始单价向上保留4位，再乘数量并十进制四舍五入到2位。
不根据面积推算布重，不把元/平方米当元/kg，不加其他未约定费用。

## 输出与状态

输出固定方向横排、纵排、穴数、含边料整张尺寸、面积平方米、每张材料费、固定加工费、三种张数及整单费用拆分。
旋转方案写“植布禁止旋转，不计算”，厚度/净重/比重写“不参与植布计价”；不要编造第二种方向或重量结果。
显示有效110×70cm上限、采用的模具及默认来源。缺价格或含税系数时列出具体缺项并用 `blocked`，不输出完整建议报价金额。
演示、未核准价格、默认模具和其他假设保持 `pending_review`；计算成功不能自动正式确认。
