# 教学算例与边界核对

本文件所有订单及价格均为虚构教学数据，不代表实际采购价、加工收费或税务口径。算例用于核对公式和取整顺序，不能作为真实订单报价。输入对应 `../assets/parameters.example.json` 与 `../assets/order.example.json`。

## 1. 完整报价算例

### 输入

| 项目 | 教学值 |
|---|---|
| 产品 | 长方形，20 × 15 × 高 3 cm |
| 模具 | 阴模；长、宽各增加总出血 1 cm |
| 设备 | 最大片材 120 × 70 cm；每方向总边料 4 cm；间距 0 |
| 材料 | PET，灰色；实测原片厚度 0.50 mm；密度 1.40 g/cm³ |
| 材料未税价 | 7.50 元/kg，虚构价格日期 2026-10-22 |
| 数量、不良率 | 6,000 个，0 |
| 加工费 | 基础 1.20 元/张；11–25 穴档差 0.25 元/张 |
| 小单收费 | 小单张数 <500 收 400 元；500–<1000 收 250 元；≥1000 收 0 元 |
| 原额转收 | 模具 300 元、包装 120 元、运费 180 元、其他 0 元 |
| 额外目标毛利率 | 0 |
| 含税系数 | 1.10，仅为此教学案例给定参数 |

### 两个方向

阴模占位为 `(20+1) × (15+1) = 21 × 16 cm`，高度不参与阴模占位。

| 项目 | 原方向 | 旋转 90° |
|---|---:|---:|
| 排数 | 5 × 4 | 7 × 3 |
| 穴数 | 20 | **21** |
| 实际片材 | 109 × 68 cm | **116 × 67 cm** |
| 片材面积 | 7,412 cm² | **7,772 cm²** |

选择旋转方向。规则先比较穴数，只有穴数相同才比较片材面积；不是直接挑面积最小的方向，也不保证这一规则等同于全局最低单位成本优化。

### 重量、张数与成本

| 项目 | 计算与结果 |
|---|---|
| 每张重量 | `7772 × 0.50 × 1.40 / 10000 = 0.54404 kg` |
| 每张材料费 | `0.54404 × 7.50 = 4.0803 元` |
| 每张加工费 | `1.20 + 0.25 = 1.45 元` |
| 连续计价张数 | `6000 / 21 / (1-0) = 2000/7 = 285.714285… 张` |
| 排产整张数 | `ceil(2000/7) = 286 张`，仅供备料 |
| 小单张数 | `6000 / 21 = 2000/7 < 500` |
| 材料总成本 | `4.0803 × 2000/7 = 1165.80 元` |
| 加工总成本 | `1.45 × 2000/7 = 2900/7 = 414.285714… 元` |
| 小单费 | `400 元` |
| 产品计价成本 | `69303/35 = 1980.085714… 元` |
| 原额转收合计 | `300 + 120 + 180 = 600 元` |

中间金额保持足够精度。表中的小数省略号只是展示，不可先四舍五入成两位再代入报价公式。

### 单价与整单金额

| 项目 | 未税 | 含税 |
|---|---:|---:|
| 原始整单金额 | 2580.085714… | 2778.094285… |
| 原始单价 | `30101/70000 = 0.430014285714…` | `324111/700000 = 0.463015714285…` |
| **单价向上保留 4 位** | **0.4301 元/个** | **0.4631 元/个** |
| **四位单价 × 数量，再取 2 位** | **2580.60 元** | **2778.60 元** |

原额转收的 600 元不参与额外毛利放大，也不乘含税系数，这是此报价方法的约定。若实际业务的计税或费用规则不同，需要先调整规则并复核。

此教学结果仍须显示“演示数据 / 不可作为正式报价”。`price_confirmed=false`，不能自动改成 `confirmed`。

## 2. 5 丝归整

只在明确启用“按高度估厚”、且有效实测厚度和净重均未提供时，采用经验厚度。1 丝 = 0.01 mm；5 丝 = 0.05 mm。

以十进制计算 `k = 参考厚度 / 0.05`，对非负 k 四舍五入到整数，恰好半档时取上档，再乘 `0.05`。不能先让二进制浮点误差改变半档位置。

| 输入 | 未归整厚度 | 正确结果 |
|---|---:|---:|
| PET，高 4.4 cm | 0.44 mm = 44 丝 | 0.45 mm = 45 丝 |
| PET，高 10.75 cm | 1.075 mm = 107.5 丝 | **1.10 mm = 110 丝** |
| PS，高 4.5 cm | 0.55 mm = 55 丝 | 0.55 mm = 55 丝 |
| PP，高 4.5 cm | `(4.5×0.1+0.1)×1.1 = 0.605 mm` | **0.60 mm = 60 丝** |
| 已填实测厚度 0.47 mm | 实测值 | **仍为 0.47 mm，不归整** |
| 有效高度推算后归整为 0 | 无可用参考档位 | 阻断并核对，不改为任意厚度 |

按高度得出的厚度始终标记“参考厚度，非实测”，状态为 `pending_review`。

## 3. 加工费差值法

虚构两个材料的第一档加工费分别为 1.20 与 0.95 元/张。当 26–36 穴档差为 0.50 时：

- 材料 A：`1.20 + 0.50 = 1.70 元/张`。
- 材料 B：`0.95 + 0.50 = 1.45 元/张`。
- 二者差额仍为 `0.25 元/张`；在使用相同档差表的每个档位，差额均应不变。

只测试第一档，或只测试恰好与参考档金额相同的材料，无法发现把“相加”误写成“相乘”的错误。

## 4. 小单费边界

使用本教学参数，不含不良率、不取整的 `数量 / 穴数`：

| 小单张数 | 小单费 |
|---:|---:|
| 499.999 | 400 元 |
| 500 | 250 元 |
| 999.999 | 250 元 |
| 1000 | 0 元 |

即使计价张数因为不良率而增加，小单档位仍由 `数量 / 穴数` 决定。

## 5. 输入与确认状态

| 情况 | 正确处理 |
|---|---|
| 厚度与净重字段都缺失，已明确启用经验估厚且高度有效 | 可以给参考厚度；保留原输入和推算来源；待人工复核 |
| 厚度明确为 0、负数、非数字或无穷值 | 标记输入错误并阻断；不能当作缺失去估厚 |
| 已给有效厚度 0.47 mm | 直接使用，不被高度经验式覆盖 |
| 只说“植绒”，未说明基材 | 确认 PET/PVC/PS 植绒，不猜材料 |
| 只有植绒净重，无法确认厚度和等效比重的配套口径 | 要求核准参数，不能代入内部胶绒成本公式 |
| 材料与颜色匹配不到采购价 | 阻断金额；不借用另一颜色的价格 |
| 缺含税系数 | 可以完成资料整理；不得捏造含税金额 |
| 默认采用阳模 | 说明原因，状态为 `pending_review`；确认模具后重新核算 |
| 模穴数超出配置覆盖范围 | 人工确认加工费，不猜新档位 |
| 没有执行计算工具 | 说明计算尚未运行；不能声称已复算或已通过测试 |

## 6. 非零不良率与毛利率

下面是两个独立的小算例，不继承第 1 节的订单金额。

- 数量 `1800`、穴数 `20`、不良率 `0.10`：连续计价张数为 `1800/20/(1-0.10)=100` 张；小单张数仍为 `1800/20=90` 张。材料与加工按 100 张计，小单档位按 90 张判断。
- 已核算产品计价成本 `1000` 元、原额转收 `100` 元、数量 `1000` 个、额外目标毛利率 `0.20`、含税系数 `1.10`：未税单价为 `(1000/(1-0.20)+100)/1000=1.3500` 元；含税单价为 `(1000×1.10/(1-0.20)+100)/1000=1.4750` 元。对应整单为 `1350.00` 与 `1475.00` 元。把毛利率误作加价率，或把 100 元转收费用一起放大，都会得到不同结果。
