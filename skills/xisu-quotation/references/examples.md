# 教学算例与边界核对

本文件订单及采购价为虚构教学数据；第1节的机器和收费采用公开参考规则。教学配置中的含税系数1.10与当前公开参考含税系数1.1相同。算例用于核对公式和取整顺序，不能作为真实订单报价。输入对应 `../assets/parameters.example.json` 与 `../assets/order.example.json`。

## 1. 完整报价算例

### 输入

| 项目 | 教学值 |
|---|---|
| 产品 | 长方形，20 × 15 × 高 3 cm |
| 模具 | 阴模；长、宽各增加总出血 1 cm |
| 设备 | 最大片材 126 × 76 cm；每方向总边料 4 cm；间距 0 |
| 材料 | PET，灰色；实测原片厚度 0.50 mm；密度 1.40 g/cm³ |
| 材料未税价 | 7.50 元/kg，虚构价格日期 2026-10-22 |
| 数量、不良率 | 6,000 个，0 |
| 加工费 | 基础 1.00 元/张；11–25 穴档差 0.20 元/张 |
| 小单收费 | 小单张数 <500 收 500 元；500–<1000 收 300 元；≥1000 收 0 元 |
| 原额转收 | 模具 300 元、包装 120 元、运费 180 元、其他 0 元 |
| 额外目标毛利率 | 0 |
| 含税系数 | 1.10，与当前公开参考含税系数1.1相同，本例按教学配置计算 |

### 两个方向

阴模占位为 `(20+1) × (15+1) = 21 × 16 cm`，高度不参与阴模占位。

| 项目 | 原方向 | 旋转 90° |
|---|---:|---:|
| 排数 | 5 × 4 | 7 × 3 |
| 穴数 | 20 | **21** |
| 实际片材 | 109 × 68 cm | **116 × 67 cm** |
| 片材面积 | 7,412 cm² | **7,772 cm²** |

选择旋转方向。规则先比较穴数，只有穴数相同才比较片材面积；不是直接挑面积最小的方向，也不保证这一规则等同于全局最低单位成本优化。

### 重量、张数与成本

| 项目 | 计算与结果 |
|---|---|
| 每张重量 | `7772 × 0.50 × 1.40 / 10000 = 0.54404 kg` |
| 每张材料费 | `0.54404 × 7.50 = 4.0803 元` |
| 每张加工费 | `1.00 + 0.20 = 1.20 元` |
| 连续计价张数 | `6000 / 21 / (1-0) = 2000/7 = 285.714285… 张` |
| 排产整张数 | `ceil(2000/7) = 286 张`，仅供备料 |
| 小单张数 | `6000 / 21 = 2000/7 < 500` |
| 材料总成本 | `4.0803 × 2000/7 = 1165.80 元` |
| 加工总成本 | `1.20 × 2000/7 = 2400/7 = 342.857142… 元` |
| 小单费 | `500 元` |
| 产品计价成本 | `70303/35 = 2008.657142… 元` |
| 原额转收合计 | `300 + 120 + 180 = 600 元` |

中间金额保持足够精度。表中的小数省略号只是展示，不可先四舍五入成两位再代入报价公式。

### 单价与整单金额

| 项目 | 未税 | 含税 |
|---|---:|---:|
| 原始整单金额 | 2608.657142… | 2809.522857… |
| 原始单价 | `91303/210000 = 0.434776190476…` | `983333/2100000 = 0.468253809523…` |
| **单价向上保留 4 位** | **0.4348 元/个** | **0.4683 元/个** |
| **四位单价 × 数量，再取 2 位** | **2608.80 元** | **2809.80 元** |

原额转收的 600 元不参与额外毛利放大，也不乘含税系数，这是此报价方法的约定。若实际业务的计税或费用规则不同，需要先调整规则并复核。

此教学结果仍须显示“演示数据 / 不可作为正式报价”。`price_confirmed=false`，不能自动改成 `confirmed`。

## 2. 5 丝归整

只在明确启用“按高度估厚”、且有效实测厚度和净重均未提供时，采用经验厚度。1 丝 = 0.01 mm；5 丝 = 0.05 mm。

以十进制计算 `k = 参考厚度 / 0.05`，对非负 k 四舍五入到整数，恰好半档时取上档，再乘 `0.05`。不能先让二进制浮点误差改变半档位置。

| 输入 | 未归整厚度 | 正确结果 |
|---|---:|---:|
| PET，高 4.4 cm | 0.44 mm = 44 丝 | 0.45 mm = 45 丝 |
| PET，高 10.75 cm | 1.075 mm = 107.5 丝 | **1.10 mm = 110 丝** |
| PS，高 4.5 cm | 0.55 mm = 55 丝 | 0.55 mm = 55 丝 |
| PP，高 4.5 cm | `(4.5×0.1+0.1)×1.1 = 0.605 mm` | **0.60 mm = 60 丝** |
| 已填实测厚度 0.47 mm | 实测值 | **仍为 0.47 mm，不归整** |
| 有效高度推算后归整为 0 | 无可用参考档位 | 阻断并核对，不改为任意厚度 |

按高度得出的厚度始终标记“参考厚度，非实测”，状态为 `pending_review`。

## 3. 加工费差值法

采用公开参考规则，以 PVC 和 PET 验证非第一档：

- 30穴：PVC `1.20+0.40=1.60`，PET `1.00+0.40=1.40`，PET植绒 `1.50+0.40=1.90` 元/张。
- 99穴：PVC `1.20+1.40=2.60`，PET `1.00+1.40=2.40`，PET植绒 `1.50+1.40=2.90` 元/张。
- PVC与PET的加工费差在各档均为0.20元/张；PET与PS、PP同档相同。

只测试第一档，或只测试恰好与参考档金额相同的材料，无法发现把“相加”误写成“相乘”的错误。

## 4. 小单费边界

使用本教学参数，不含不良率、不取整的 `数量 / 穴数`：

| 小单张数 | 小单费 |
|---:|---:|
| 499.999 | 500 元 |
| 500 | 300 元 |
| 999.999 | 300 元 |
| 1000 | 0 元 |

即使计价张数因为不良率而增加，小单档位仍由 `数量 / 穴数` 决定。

## 5. 输入与确认状态

| 情况 | 正确处理 |
|---|---|
| 厚度与净重字段都缺失，已明确启用经验估厚且高度有效 | 可以给参考厚度；保留原输入和推算来源；待人工复核 |
| 厚度明确为 0、负数、非数字或无穷值 | 标记输入错误并阻断；不能当作缺失去估厚 |
| 已给有效厚度 0.47 mm | 直接使用，不被高度经验式覆盖 |
| 只说“植绒”，未说明基材 | 确认 PET/PVC/PS 植绒，不猜材料 |
| 材料与颜色匹配不到采购价 | 阻断金额；不借用另一颜色的价格 |
| 缺含税系数 | 可以完成资料整理；不得捏造含税金额 |
| 默认采用阳模 | 说明原因，状态为 `pending_review`；确认模具后重新核算 |
| 模穴数超出配置覆盖范围 | 人工确认加工费，不猜新档位 |
| 没有执行计算工具 | 说明计算尚未运行；不能声称已复算或已通过测试 |

## 6. 非零不良率与毛利率

下面是两个独立的小算例，不继承第 1 节的订单金额。

- 数量 `1800`、穴数 `20`、不良率 `0.10`：连续计价张数为 `1800/20/(1-0.10)=100` 张；小单张数仍为 `1800/20=90` 张。材料与加工按 100 张计，小单档位按 90 张判断。
- 已核算产品计价成本 `1000` 元、原额转收 `100` 元、数量 `1000` 个、额外目标毛利率 `0.20`、含税系数 `1.10`：未税单价为 `(1000/(1-0.20)+100)/1000=1.3500` 元；含税单价为 `(1000×1.10/(1-0.20)+100)/1000=1.4750` 元。对应整单为 `1350.00` 与 `1475.00` 元。把毛利率误作加价率，或把 100 元转收费用一起放大，都会得到不同结果。


## 7. 参考配置的缺项检查

读取 `../assets/parameters.reference.json` 可以直接获得机器、10种材料基础加工费、6档加工费差额和3档小单费，不需要使用者再逐项输入。
只给产品尺寸和数量、未给材料采购价或含税系数时，列出这两项缺失并保持 blocked，不从教学配置借7.50或1.10。
参考配置已提供材料颜色与价格；材料可采用参考单价和比重进行简易估价。补齐数值后仍须人工复核，不能仅因 is_demo=false 自动正式确认。

2026-10-22完整数值版已把原教学收费400/250改为公开参考收费500/300，并将PET加工费改为1.00加档差0.20。第1节的新结果为未税0.4348、含税0.4683元/个；旧版0.4301/0.4631不再适用于更新后的教学配置。

## 8. 植布完整教学算例

成套输入为 `../assets/parameters.cloth.example.json`、`../assets/order.cloth.example.json`，完整规则见 [植布规则](cloth-rules.md)。
虚构订单35×15×高1cm、10000个；模具未提供，因此暂按阴模。教学材料价16元/平方米、含税系数1.10与当前公开参考值相同。本例金额只核算该教学订单，不能当作客户报价。固定加工3元/张；额外不良率和毛利率均0；各项原额转收费用明确为0。

- 通用机器126×76cm受植布上限约束，有效整张110×70cm；每方向两端边料合计4cm，间距0，总出血1cm。
- 占位36×16cm；仅原方向 `floor(106/36) × floor(66/16)=2×4=8穴`。旋转禁止，不计算第二方向。
- 实际片材 `2×36+4=76cm`、`4×16+4=68cm`，面积5168cm²＝0.5168平方米。
- 每张材料费 `0.5168×16=8.2688元`；每张加工费固定3元，无穴数差额。
- 连续计价张数 `10000/8=1250`，备料1250整张，小单判断1250张，小单费0元。
- 材料总成本10336元，加工3750元，产品计价成本14086元，原额转收0元。
- 未税原始单价1.4086元，向上四位仍为 **1.4086元/个**，整单 **14086.00元**。
- 含税原始单价1.54946元，向上四位为 **1.5495元/个**，整单 **15495.00元**。
- 不输出厚度、净重或比重计算。保持 `is_demo=true`、`price_confirmed=false`、`pending_review`；模具采用默认值也须保留假设。

### 植布边界核对

| 输入/条件 | 结果 |
|---|---|
| 阴模长105、宽65cm，总出血1、边料合计4 | 1穴，整张恰好110×70cm，允许 |
| 同条件长105.01或宽65.01cm | 原方向放不下，阻断，不旋转补救 |
| 阴模15×80cm | 宽超限；即使交换后能放入也阻断 |
| 通用设备更小，如100×60cm | 实际采用100×60cm，不放宽到110×70 |
| 阳模15×17×高5.5cm | 保留阳模，仅原方向5×2＝10穴，106.5×49cm；材料8.3496元/张，加工仍3元/张 |
| 植布100穴以上且尺寸合法 | 固定加工仍为3元/张，不匹配普通档差 |
| 植布材料面积单价或含税系数缺失 | blocked；不借教学16或1.10 |
| 材料价0、负数；固定加工费负数或非有限数 | 阻断；固定加工费明确为0可以接受 |
| 植布遗留厚度/克重/比重字段 | 不参与计算，不进行估厚；普通材料显式零厚度仍阻断 |

植布与普通材料共用小单张数规则，499.999/500/999.999/1000张分别收500/300/300/0元。显式修改固定加工费时按新值整单计价，仍不加穴数档差。

## 10. 体积运费完整教学算例

成套使用 [体积运费参数](../assets/parameters.freight.example.json) 和 [体积运费订单](../assets/order.freight.example.json)。产品及材料采用第1节的虚构教学输入，成品6000个。PET灰色采购价7.50只用于此例；含税系数1.10与当前公开参考含税系数1.1相同。

- 21穴、116×67cm，产品计价成本仍 `70303/35=2008.657142…元`。
- 每箱700个，箱尺寸50×40×30cm，运价150元/m³，均为本例明确给定。
- 箱数 `ceil(6000/700)=9`；最后不足一箱仍计一箱。单箱体积 `50×40×30÷1000000=0.06m³`。
- 整单运费 `round_half_up_2(9×0.06×150)=81.00元`，不是每个产品或每张片材的费用。
- 模具300、包装120、其他0，加运费81，原额转收合计 **501.00元**；不参加毛利放大或含税系数计算。
- 未税原始单价0.418276190476…，向上四位 **0.4183元/个**，整单 **2509.80元**。
- 含税原始单价0.451753809523…，向上四位 **0.4518元/个**，整单 **2710.80元**。

每箱装量缺失、0、负数、非整数时阻断运费；缺箱尺寸或运价时列出缺项，不借默认装箱比例。手填模式只用整单amount，自提为0，不能与volume同时加收。保留演示、未核准价格和待复核状态。

## 11. 触感PET与镀金PET的参数及估厚检查

两种材料分别登记：参考密度1.40g/cm³、基础加工费1.50元/张，采购价和含税系数由使用者提供。名称必须精确匹配；不能把它们当普通PET的价格或1.00元/张加工费。

| 检查 | 两种材料各自的结果 |
|---|---|
| 30穴加工费 | 1.50+0.40＝1.90元/张 |
| 99穴加工费 | 1.50+1.40＝2.90元/张 |
| 有效实测原片厚度0.47mm | 原值使用，不归整 |
| 只有有效净重21g，投影20×15cm，采用参考密度1.40 | 等效厚度21×10÷(300×1.40)＝0.50mm，标记估算待复核 |
| 厚度和净重均缺失，高4.4cm，启用估厚 | PET规则0.44mm，归整到0.45mm |
| 厚度和净重均缺失，高10.75cm，启用估厚 | PET规则1.075mm，半档取上到1.10mm |
| 已明确填写厚度0 | blocked，不改用高度估厚 |
| 缺采购价或含税系数 | blocked，不从普通PET或教学配置借值 |

复用PET类别只用于厚度经验规则；颜色价格、独立材料名称、1.50元/张基础加工费及来源记录均须保留。
