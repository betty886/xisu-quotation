# 吸塑报价计算规则

本文件定义公开版的计算方法。设备和收费可采用 [公开参考配置](../assets/parameters.reference.json)，具体数值也列在 [技能入口](../SKILL.md)；使用者可覆盖。材料采购价与含税系数必须自行提供。公式不变。

材料为植布时先按 [植布规则](cloth-rules.md)执行：面积计价、110×70cm整张上限、禁止旋转、缺模具默认阴模、固定加工费。下文重量和两方向排版仅适用于普通/植绒，公共费用与取整规则仍适用于植布。

## 1. 单位、参数与有效性

尺寸与片材长宽为 cm，面积为 cm²，厚度 T 为 mm，单件净重 w 为 g，密度 ρ 为 g/cm³。
普通/植绒材料价 P 为未税元/kg；植布使用未税元/平方米。单张加工费为元/张；所有整单费用使用同一币种。
Q 为正整数订单数量；不良率 r、额外毛利率 m 使用小数，均须满足 `0 ≤ 值 < 1`。
含税系数 τ 为使用者确认的正数商业报价系数，不据此推断税种、法定税率或发票税额。
未提供自有配置时，机器、边料、间距、基础加工费、穴数档差、小单费和普通材料参考密度采用公开参考配置；实际适用性须复核。采购价与含税系数无默认值，植绒比重须配套核准。
费用允许明确填写零；价格、尺寸和数量要求正数；普通/植绒采用的密度、厚度、净重要求正数，植布不使用这三项。缺失不等于零。
空缺/null 可表示未知；非数字、非有限数、布尔值及不符合取值范围的已填值是无效输入。
材料及颜色精确匹配；记录价格日期与核准状态。示例配置不得作为真实订单的自动回落值。
优先采用本次明确提供且经核对的参数；与配置冲突时先澄清，不自行选较便宜的一组。
金额和分档边界须用十进制或精确单位计算；π、√3 由执行工具计算并保持足够中间精度。

## 2. 投影面积与排版外框

反推厚度使用真实平面投影面积 A；排版使用外框长 L、外框宽 W。两者用途不同。

| 形状 | 投影面积 A | 排版外框 L、W |
|---|---|---|
| 长方形/正方形 | 长 × 宽 | 长、宽 |
| 圆形 | π × D² / 4 | D、D |
| 椭圆形 | π × 长轴 × 短轴 / 4 | 长轴、短轴 |
| 正六边形 | 3√3 × D² / 8，D 为长对角线 | D、√3 × D / 2 |
| 三角形 | 底 × 平面垂直高 / 2 | 使用者提供的外接矩形长宽 |
| 自定义异形 | 使用者提供的实际投影面积 | 使用者提供的外框长宽 |

三角形的平面垂直高不等于产品立体高度 H。面积与外框必须为正且相容。
不能用圆形、六边形等外接矩形面积反推厚度。异形缺实际投影面积时不能伪造面积。

## 3. 厚度来源和经验估厚

### 3.1 实测与净重反推

有有效实测原片厚度时直接采用，不归整实测值。普通材料只有有效净重时：

`T = w × 10 / (A × ρ)`

标注“净重反推的等效厚度估算”，保持待复核；复杂成型件的等效厚度不自动等于实际原片厚度。
有实际领料资料时，可用 `领料总重(kg) × 1000 / 合格品数量` 复核每合格件耗料，不能与边料损耗重复叠加。
厚度与净重都给出时，采用明确的实测原片厚度；发现两者明显不一致时列出差异并复核。

### 3.2 可明确启用的高度经验估厚

仅当厚度、净重都确实缺失，H 是有效正数，且使用者已明确启用该经验方法时使用。
已有无效厚度/净重时先纠错；不允许通过经验值覆盖。未登记材料须先选定并声明适用的经验规则。

| 材料类别 | 未归整的参考厚度 v（mm），H 用 cm |
|---|---|
| PET、PET透明、PET植绒、PVC、PVC植绒 | H × 0.1 |
| PS、PS植绒 | H × 0.1 + 0.1 |
| PP | (H × 0.1 + 0.1) × 1.1 |

完整识别材料名称及已确认的类别，不以单个字母 P 匹配所有材料；未知材料不得借用其价格或密度。
`1 丝 = 0.01 mm`；最近 5 丝档即 `0.05 mm`，居中取上档。按十进制精确计算：

```text
原值丝数 s = v × 100
归整丝数 k = floor(s / 5 + 0.5) × 5
参考厚度 T = k / 100
```

使用十进制数或等价的精确整数缩放，在归整前消除二进制浮点误差；不要先用浮点除 0.05 再修尾数。
PET 高 10.75 cm：107.5 丝取 110 丝；PP 高 4.5 cm：60.5 丝取 60 丝；PET 高 4.4 cm：44 丝取 45 丝。
若归整为零，停止估厚并要求核对，不回退到非 5 丝档。保留原值、采用值、原因及 `pending_review`。
输出“按高度推算的参考厚度，非实测”；这是一种初步报价经验，不是适用于所有产品的厚度标准。

### 3.3 植绒公共版边界

使用核准的成品片材未税单价 P 和等效比重 ρeq；它们必须与本单采用的裸基材厚度 T 配套。
后续材料重量式用该 T 和 ρeq，不能将成品总厚度与基于裸片厚度的等效比重混用。
只有植绒净重时，不套普通材料反推式，不计算内部配方；要求使用者核准裸片厚度、净重性质和比重口径。
明确是成品厚度时，先取得核准的裸片厚度与相应等效比重。高度估厚也不能替代这一配套确认。
不从另一厚度、另一材料或另一颜色继承植绒单价/等效比重；不包含植绒内部成本或工位机利润核算。

## 4. 阴阳模及两方向排版

设机器最大片材为 ML × MW；EL、EW 分别为两个方向的两端边料合计，g 为产品间距。
要求 `ML > EL ≥ 0`、`MW > EW ≥ 0`、`g ≥ 0`。EL/EW 已是两端合计，不能再乘二。
阴模总出血位为 b；b 同样是该方向合计，不是每边出血。

```text
阴模：X = L + b；Y = W + b             （不加产品高度）
阳模：X = L + H；Y = W + H
横排 c = floor((ML − EL + g) / (X + g))
纵排 d = floor((MW − EW + g) / (Y + g))
穴数 n = c × d
实际片长 SL = c × X + (c − 1) × g + EL
实际片宽 SW = d × Y + (d − 1) × g + EW
片材面积 S = SL × SW
```

普通/植绒分别计算 `(X,Y)` 与旋转 90° 的 `(Y,X)`；机器方向及 EL/EW 不随产品旋转交换。
淘汰横排或纵排小于一、片材超限的方案。优先穴数多，其次片材面积小；仍相同可保留原方向并说明。
两方向都排不下则阻断，不把穴数设为一强行计算。圆形按外接正方形直排，不虚构梅花排版。
普通/植绒已核准的实际模穴数及拉片尺寸可覆盖理论排版，但须成套提供并记录来源，重新检查设备与档位约束。
普通/植绒只有确实缺模具且允许初步默认时，暂按阳模并保留来源；有效阴/阳模输入优先，无效名称不能被替换。

## 5. 材料成本与三种张数

普通材料使用核准密度 ρ；符合第 3.3 节的植绒使用 ρeq。植布每张材料费＝SL×SW÷10000×未税元/平方米，不用下面的重量式；三种张数定义相同。

```text
每张片材重量 K（kg）= S × T × ρ / 10000
每张材料费 = K × P
连续计价张数 Nc = Q / n / (1 − r)
排产整张数 Np = ceil(Nc)
小单张数 Ns = Q / n
材料总成本 Cmat = K × P × Nc
```

材料费与加工费使用 Nc，不提前取整；Np 仅用于备料；Ns 不加不良率、不取整。
片材尺寸已含边料，不能再重复加边料损耗。不良率只在 Nc 使用一次，不额外重复放大费用。

## 6. 加工费与小单费

本节穴数档差仅适用于普通/植绒；植布固定加工费参考3元/张，不匹配档位，超过100穴也不加差额。

设使用者提供的该材料第一档基础加工费为 B，命中档位金额为 Dj，第一档金额为 D1：

`档差 Δj = Dj − D1；每张加工费 Fsheet = B + Δj；加工总成本 Cproc = Fsheet × Nc`

也可直接提供 Δj。参数模板的 `surcharge_per_sheet` 已表示档差，直接加 B，不能再次加档位金额。
第一档档差为零。检查穴数区间明确、无重叠、无缺口且覆盖 n；超出最高档则阻断并补规则。
金额须有效、最终每张加工费须非负。不能改为 `B × Dj / D1`，也不能一律只用 Dj。
同一档位下两种材料的加工费差，应等于二者基础费差。核对加工费时应包含非第一档案例。
`Fsheet / n` 仅是不含不良率放大的单件基础加工费；订单实际分摊应使用 `Cproc / Q`。

按 Ns 在采用配置的小单张数区间中匹配整单小单费 Csmall，只收一次。公开参考规则为 Ns<500 收500元，500≤Ns<1000 收300元，Ns≥1000 收0元；使用者可提供自己的完整规则覆盖。
模板采用“下限包含、上限不包含”，最后一档上限 null 表示无穷；显式免收也是一条规则。
不能按订单件数、Np 或 Nc 判小单费；缺小单规则不能静默当零。

## 7. 运费、原额转收与整单建议价

### 7.1 运费和费用范围

运费由使用者明确选择：自提为零、手填整单金额，或提供完整装箱参数后按体积计算。

```text
箱数 = ceil(Q / 每箱装量)
单箱体积（m³）= 箱长(cm) × 箱宽(cm) × 箱高(cm) / 1000000
整单运费 = round_half_up_2(箱数 × 单箱体积 × 每立方运价)
```

每箱装量须为正整数；箱尺寸、运价及币种须明确。缺数据不套用历史装箱比例或隐含运费。
原额转收 F = 模具费 + 包装费 + 其他费用 + 运费。各项整单计一次，允许使用者明确填写零。
本方法中 F 不参加毛利放大、不乘 τ；若业务要求不同费用口径，先约定新规则，不能暗改公式。

### 7.2 成本、毛利与取整

额外目标毛利率未指定时采用 m=0 并披露；这不代表加工收费无利润，也不代表整单净利润为零。
m 是毛利率而非加价率；不能把除以 `(1−m)` 替换成乘以 `(1+m)`。

```text
产品计价成本 C = Cmat + Cproc + Csmall
整单未税成本 = C + F
未税原始单价 u0 = [C / (1 − m) + F] / Q
含税原始单价 u1 = [C × τ / (1 − m) + F] / Q
ceil4(u) = ceil(u × 10000) / 10000
未税建议单价 U0 = ceil4(u0)；含税建议单价 U1 = ceil4(u1)
未税整单 G0 = round_half_up_2(U0 × Q)
含税整单 G1 = round_half_up_2(U1 × Q)
```

按订单约定选 G0 或 G1 为所报总额；清楚区分两种单价。先取四位单价，再乘数量，不能倒序。
`round_half_up_2` 表示十进制四舍五入到两位，不采用银行家舍入；其余中间成本保留精度。
最低毛利率仅在使用者明确设置时生效；用同一公式代入该最低率计算同口径底价。
手填报价低于已设置底价时展示差额并阻断正式确认；未设置时输出“未设置底价判断”。

## 8. 复核状态与边界检查

缺关键价格、密度、工艺参数、规则或遇到无效输入时用 `blocked`，不输出可执行报价金额。
教学、未核准价格、模具默认、净重反推或高度估厚等结果用 `pending_review`；记录原输入、采用值、来源、原因和待核对项。
计算成功不能自动消除估算标记；只有参数与业务口径复核完成并获使用者确认，才记录 `confirmed`。
正式确认前复核实际厚度、材料颜色及现行采购依据、实际模穴数、运费和适用收费规则。
使用执行工具检查：普通/植绒两方向排版及非第一档差值，植布仅原方向及固定加工费；同时检查张数分档上下边界、不良率仅用一次、费用只转收一次。
检查估厚的半档取上、归整为零、未知材料、显式零/负数/非法输入、已有实测值不变及植绒净重限制。
同时核对取整前后单价和整单金额；保留实际执行证据。没有计算工具时只能交付待核对的方法说明。
