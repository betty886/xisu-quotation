# 送货单版式

公开仓库使用 `templates/delivery-note-anonymized.xlsx`。这是脱敏范本：示例塑料制品有限公司、示例客户、虚构数量和金额，没有印章。真实抬头和真实订单留在仓库外；生成正式件时改用仓库外的正式范本，不要把那份文件提交进来。

生成时复制范本，只改可变单元格，保留合并、列宽、行高、边框、打印设置和公式。当前脱敏工作簿把第 1–34 列的列宽记为 4.1，生成程序不把列宽改写成别的数值。

- 工作表只有可见的「送货单」。纸张 A4 横向，打印区域 `送货单!$A$1:$AH$20`，水平垂直居中。
- 客户名未知时只留「客户名称：」。电话、地址、联系人、单号未提供就只留标签，不编造，也不沿用旧单。
- 送货日期用本次出货日期，格式 `送货日期：YYYY-MM-DD`。
- 产品金额公式为 `=ROUND(数量*单价,2)`。合计为 `=SUM(Z8:Z13)`。
- 模具费单独一行。没有模具费时保留名称「模具费」，金额留空，不写 0。
- 人民币大写是按合计重写的纯文本，不是公式。
- 单价超过两位小数时保留足够位数，不先四舍五入成两位。
- 签栏只保留文字，不盖章、不签字。
- 用 LibreOffice：`soffice --headless --convert-to pdf`。

数量必须是这次实际出货的数量。报价数量不能自动写成已交货。
